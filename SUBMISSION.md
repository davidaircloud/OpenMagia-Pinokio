# Publishing checklist

## Direct installation release

1. Create a public GitHub repository named `OpenMagia-Pinokio` under the OpenMagia publisher account.
2. Push this repository's `main` branch.
3. Import `https://github.com/davidaircloud/OpenMagia-Pinokio` in Pinokio and complete every applicable item in [TESTING.md](TESTING.md).
4. Share the direct-install URL only after the clean-machine results are recorded:
   `https://pinokio.co/item?uri=https://github.com/davidaircloud/OpenMagia-Pinokio`

## Registry / Discover request

After direct-install validation:

1. Prepare a feature-request issue with the launcher URL, app description, platform matrix, and exact local verification evidence. A recent example is [Pinokio issue #1100](https://github.com/pinokiocomputer/pinokio/issues/1100).
2. Follow Pinokio's current [script policy](https://github.com/pinokiocomputer/pinokio#script-policy). Verified Discover placement requires publisher verification, Pinokio Factory membership, repository transfer, freeze, and review.
3. Contact [@cocktailpeanut](https://x.com/cocktailpeanut) for publisher verification.
4. Transfer only this launcher repository—not the OpenMagia application repository—to Pinokio Factory when requested.

Do not describe a registry listing as endorsement, and do not claim verified compatibility before Pinokio completes its review.
